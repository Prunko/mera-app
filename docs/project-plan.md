\# Архітектурний план проєкту: Веб-сайт гуртожитку



\## 1. Проблема та мета

Заміна ручного обліку кімнат та паперових заявок на поселення зручною веб-системою для студентів та коменданта.



\## 2. Користувачі та ролі

\- \*\*Студент / Вступник:\*\* перегляд каталогів кімнат, фільтрація, подача заявки на поселення.

\- \*\*Адміністратор (Комендант):\*\* управління кімнатами, зміна статусів наявності місць, обробка заявок.



\## 3. Структура сторінок

1\. \*\*Головна (`/`):\*\* опис гуртожитку, правила, каталог вільних кімнат.

2\. \*\*Сторінка кімнати (`/room/:id`):\*\* детальна інформація, меблі, фото, кількість місць.

3\. \*\*Оформлення заявки (`/apply`):\*\* форма для введення даних студента та вибору кімнати.

4\. \*\*Панель коменданта (`/admin`):\*\* список та обробка всіх заявок.



\## 4. Технологічний стек

\- \*\*Frontend:\*\* React + Vite

\- \*\*Стилізація:\*\* CSS / Tailwind

\- \*\*Збереження даних:\*\* JSON / LocalStorage (на початковому етапі)
